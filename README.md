# 摸鱼二号（FishTwo）

> 一款为 Microsoft Edge 打造的本地图片批量阅读扩展：选一个文件夹，按文件名自然排序，用三种模式沉浸式阅读。

Edge 本身无法直接打开本地文件夹并批量识别图片，逐张点开相册、漫画、截图既割裂又低效。**摸鱼二号**只做一件事——把「一个文件夹里的图片」变成干净、顺手的阅读体验。

- 扩展规范：Manifest V3
- 构建：WXT（底层 Vite）
- 界面：React 19 + TypeScript

---

## 功能特性

### 导入与排序

- 通过 `showDirectoryPicker` 选择本地图片文件夹，仅扫描**顶层**文件。
- 支持 `jpg / jpeg / png / webp / gif / bmp`。
- 按文件名**自然排序**（`2.png` 排在 `10.png` 之前）。
- 检测到子文件夹时提示「只能导入单一文件夹」，并忽略子文件夹内容。
- 持久化目录句柄，二次打开自动恢复；权限被回收时提供「重新授权」。
- 最多记录 5 个最近文件夹，去重、最近置顶、可一键打开。

### 三种阅读模式

| 模式 | 说明 |
|---|---|
| 下拉滚动 | 图片纵向连续排列，滚轮浏览，底栏显示百分比进度 |
| 单页翻页 | 一次一页，支持方向键 / 点击 / 滚轮翻页 |
| 双页翻页 | 漫画式排版：首屏封面单页，之后两页一组（间距 16px） |

模式切换即时生效；单/双页模式下滑到舞台两侧会浮现圆形翻页箭头（首尾或非 100% 缩放时自动隐藏）。

### 缩放与还原

- `Ctrl + 滚轮` 以鼠标位置为中心缩放（10% ~ 500%），并拦截浏览器整页缩放。
- 底栏 `− / 百分比 / +` 按钮以舞台中心缩放，点击百分比一键复位 100%。
- 双击图片或点击「还原」恢复原始尺寸；放大后可拖拽平移查看细节。

### 目录栏与定位

- 左侧图片名称列表（无缩略图），带序号与当前项高亮条。
- 顶部搜索框输入即过滤，可一键清空，并显示图片总数。
- 点击名称按当前模式跳转：滚动模式精确定位，翻页模式跳页。
- 阅读位置与列表**双向同步**，当前项自动滚入视野。
- 按文件夹分别记忆阅读位置，重开同一文件夹自动续读。

### 界面与配置

- 亮 / 暗双主题，统一设计令牌与薄荷绿品牌色，支持平滑过渡。
- 三段式顶栏（品牌 + 导入 + 文件夹 / 模式切换 / 目录、主题、快捷键、沉浸）与底部信息栏（页码或进度、文件名、缩放）。
- 顶部与底部两栏均可隐藏，隐藏后悬浮吸边可随时唤回；沉浸模式同步隐藏目录栏。
- 中英文界面切换，配置经 `chrome.storage.sync` 同步，阅读器实时生效。
- popup 弹窗：语言、主题、隐藏快捷键、最近文件夹与「打开阅读器」入口。

### 性能

- 图片按需读取：`IntersectionObserver` 接近视口才创建 object URL，卸载时 `revokeObjectURL` 回收。
- 滚动模式当前索引由位置二分查找得出（O(log n)），懒加载改变高度也不会错位。
- 目录异步遍历，避免一次性加载全部文件。

## 快捷键

| 操作 | 按键 |
|---|---|
| 上一页 | `←` / `↑` / `PageUp` |
| 下一页 | `→` / `↓` / `PageDown` |
| 缩放 | `Ctrl` + 滚轮 |
| 还原 100% | 双击图片 |
| 显示 / 隐藏目录栏 | `D` |
| 沉浸模式（隐藏工具条） | `F`（可在 popup 中改为其他字母键） |
| 快捷键说明 | `?` |
| 关闭说明面板 | `Esc` |

> 在搜索框等输入场景下不会触发全局快捷键。

## 快速开始

```bash
# 安装依赖
npm install

# 开发（Edge，热更新）
npm run dev:edge

# 生产构建（Edge，MV3）
npm run build:edge

# 类型检查
npm run compile

# 打包 zip
npm run zip:edge
```

### 在 Edge 中加载

1. 执行 `npm run build:edge`，生成 `.output/edge-mv3/`。
2. 打开 `edge://extensions`，开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择 `.output/edge-mv3` 目录。
4. 点击工具栏图标打开弹窗，点「打开阅读器」，再点「导入文件夹」选择图片目录。

```text
FishTwo/
├─ entrypoints/
│  ├─ popup/            # 工具栏弹窗（配置 + 打开阅读器）
│  └─ reader/           # 阅读页（核心，独立标签页）

│  ├─ db.ts             # IndexedDB 句柄与最近文件夹持久化
│  ├─ paging.ts         # 双页分页计算
│  ├─ config.ts         # chrome.storage 配置与阅读位置
│  └─ i18n.ts           # 中英文文案与语言检测
├─ types/               # File System Access 类型补全

├─ docs/                # 需求、开发、测试文档

```

## 存储与权限

| 存储 | 位置 | 内容 |
|---|---|---|
| 配置 | `chrome.storage.sync` | 语言、默认模式、主题、默认缩放、隐藏快捷键 |
| 缩放记忆 | `chrome.storage.local` | 上次缩放比例 |
| 阅读位置 | `chrome.storage.local` | 按文件夹名分别记录当前图片索引 |
| 目录句柄 | IndexedDB `fishtwo` → `handles` | 最近目录句柄与历史 |

权限遵循最小化：仅声明 `storage`。File System Access API 属于 Web 平台能力，**不需要** host 权限，**不需要** content script，不向任何网页注入内容。

## 已知限制

- `showDirectoryPicker` 依赖用户手势与原生对话框，只能在 reader 全页触发，无法在 popup 中完成导入。
- 浏览器可能回收文件夹权限，此时需点击「重新授权」。
- 目录栏未做虚拟滚动（当前仅渲染文件名文本，DOM 成本低）。
- 巨型图片尚未使用 `createImageBitmap` 异步解码与降采样预览。
- 组合「缩放 + 平移」后再次缩放时，锚点存在轻微偏差。
