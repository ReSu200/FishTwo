## 3. 阶段实现说明

### 阶段一 · 脚手架与基础结构
- WXT + React + TS 脚手架，`@wxt-dev/module-react` 模块启用 React。
- 两个入口：`popup`（弹窗）与 `reader`（阅读页）。
- 阅读页通过 `browser.tabs.create({ url: browser.runtime.getURL('/reader.html') })` 打开。
- 图标：`scripts/generate-icon.mjs` 用纯 Node（zlib + 手写 PNG 编码 + SDF 绘制）生成鱼形基础图，`@wxt-dev/auto-icons` 派生各尺寸。风格参考 FishOne：薄荷绿底、深青鱼身、白色眼睛。

### 阶段二 · 导入 / 识别 / 持久化
- `showDirectoryPicker` 选文件夹（需用户手势，故在 reader 全页进行）。
- `scanTopLevelImages` 仅遍历顶层，识别 `jpg/jpeg/png/webp/gif/bmp`，按文件名自然排序（`localeCompare({ numeric: true })`）；检测到子文件夹时返回 `hasSubfolders` 提示「只能导入单一文件夹」。
- `utils/db.ts` 用 IndexedDB 持久化目录句柄，实现「记住最近打开」：读取器打开时若权限仍有效自动恢复，权限为 `prompt` 时提供「重新授权」。

### 阶段三 · 三种阅读模式 + 状态栏
- **下拉滚动**：图片纵向排列，滚轮浏览。
- **单页翻页**：一次一页。
- **双页翻页**：漫画式，第 1 页单页（封面），之后两页一组（`utils/paging.ts`）。
- 翻页：`←`/`↑`/`PageUp` 上一页、`→`/`↓`/`PageDown` 下一页；单/双页下点击左/右半区翻页（200ms 防双击误触）；滚轮上下翻页（350ms 防抖）。
- 状态栏：顶部（导入、模式切换、还原、隐藏）+ 底部（页码/总数、当前文件名、缩放比例）。
- 隐藏/唤回：`F` 键或「隐藏」按钮；隐藏后顶部/底部悬浮条唤回。

### 阶段四 · 缩放与还原
- `Ctrl + 滚轮` 缩放，范围 10% ~ 500%，以鼠标位置为中心（单/双页用 `transform: scale` + 动态 `transform-origin`，下拉滚动用 CSS `zoom`）。
- 还原：双击图片或「还原」按钮恢复 100%；底部状态栏实时显示比例。
- 使用原生非被动 `wheel` 监听确保 `preventDefault` 生效，拦截浏览器整页缩放。

### 阶段五 · 配置 + 国际化
- 配置存 `chrome.storage.sync`，读取器经 `storage.onChanged` 实时同步主题与语言。
- 配置项：语言（跟随浏览器/中文/English）、默认阅读模式、主题（亮/暗）、默认缩放（100%/记忆上次）、隐藏快捷键（默认 F，可改）。
- 缩放记忆存 `chrome.storage.local`（`zoomDefault=memory` 时持久化并恢复）。
- UI 文案用 JS 字典（`utils/i18n.ts`）驱动手动切换；扩展名/描述经 `_locales` + `__MSG_*__` 本地化。
- 暗色主题通过 `document.documentElement.dataset.theme` 切换，CSS 用 `[data-theme='dark']` 变量覆盖。

### 阶段六 · 性能优化
- 下拉滚动模式图片懒加载：`ImageItem` 用 `IntersectionObserver`（`rootMargin: 400px`）仅在接近视口时才 `getFile()` 创建 object URL。
- object URL 在组件卸载时 `revokeObjectURL` 回收。
- 目录遍历本身为 `for await`（异步）。

## 4. 构建与运行

```bash
# 安装依赖
npm install

# 开发（Edge 启动，热更新）
npm run dev:edge

# 生产构建（Edge，MV3）
npm run build:edge

# 类型检查
npm run compile

# 打包 zip
npm run zip:edge
```

**在 Edge 中加载**：
1. `npm run build:edge` 生成 `.output/edge-mv3/`。
2. 打开 `edge://extensions`，开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择 `.output/edge-mv3` 目录。
4. 点击工具栏图标弹出配置，点「打开阅读器」进入阅读页，点「导入文件夹」选择图片目录。

## 6. 权限说明

遵循最小权限：无需 host 权限、无需 content script。File System Access API 为 Web 平台能力，扩展仅需最基本权限；manifest 未声明任何 `permissions`。

## 7. 关键决策与已知限制

1. **语言切换**：`chrome.i18n.getMessage` 无法在运行时手动切换语言，故 UI 文案用 JS 字典实现，扩展名/描述仍走 `_locales`。
2. **默认阅读模式**：作为初始模式在打开阅读器时应用；主题与语言支持实时同步。
3. **缩放平移**：当前缩放为「光标锚定」，未实现拖拽平移（超出部分可先用键盘/滚轮翻页），可在后续版本补充。
4. **目录栏虚拟滚动**：当前目录仅渲染文件名（无缩略图、成本低），未做虚拟滚动；图片主体已做视口懒加载。
5. **动图（gif）**：浏览器原生播放，按普通图片处理。
